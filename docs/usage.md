# 使用说明

> 给用的人看的。装环境和部署看 [README](../README.md)。

## 组长：三步开张

1. 打开网址 → **建一个小组**
2. 填小组名、你的昵称，选每周至少练几天（默认 5 天）、单次至少多久（默认 30 分钟）
3. 进去之后点左上角的 **复制邀请**，把链接发进群

链接长这样：`https://你的域名/g/ABC234`。谁点开都能加入，不需要审批。

## 朋友：两步开始

1. 点群里的链接
2. 在名单里点自己（第一次进来点「名单里没有我，我是新人」，填个昵称选个头像）

之后再打开链接直接就是自己的视图，不用再选。

## 每天怎么用

**点一下「今天动了」，结束。**

盖章之后会弹出补充面板，运动类型、时长、一句话、今日体重 —— **全部可选，直接关掉也算打卡成功**。多填的东西只是让个人页的记录好看一点，不影响打卡是否成立。

> 为什么不强制填时长？填得越多，坚持的人越少。打卡这个动作必须快到没有心理成本。

## 打卡墙怎么看

主页中间那块网格就是全部信息：

```
        一 二 三 四 五 六 日 上周
🐬 小雨  ✓ ✓ ✓ ✓ ✓ · ·   7
🐺 阿哲  ✓ · · · · · ·   2
🥝 Kiwi  ✓ ✓ 补 ✓ · · ·   4
```

| 符号 | 含义 |
|---|---|
| **✓** 朱红印章 | 当天打了卡 |
| **补** 虚线印章 | 补的卡，一眼能认出来 |
| 点线空格 | 过去的日子，没打卡 |
| 实线虚框 | 今天，还没打卡（只有自己那行是深色的） |
| 淡框 | 还没到的日子 |
| **上周** 那一列 | 上周打了几天。**墨黑 = 达标，朱红 = 没达标** |

顶上朱红色的那个星期几和小圆点就是今天。

「上周」这一列是特意加的：周一时本周还没有任何数据，光看本周等于什么都没看到。

## 补卡规则

**只能补昨天，7 天内只有 1 次机会。**

昨天没打卡且额度还在时，打卡按钮下面会出现「昨天练了但忘了打卡？补一次」。点掉就用完了，下次要等 7 天后。

补的卡在墙上显示成虚线的「补」字，跟正常打卡区分得清清楚楚 —— 补卡是给忘记的人留的台阶，不是给偷懒的人留的后门。

## 体重和排行

- 排行榜比的是**减重百分比**，不是绝对公斤数。基数不同的人比绝对数字不公平，也会让人不敢参加。
- **第一次记的体重自动成为你的起始体重**，不用单独设置。
- 默认**不公开体重数字**，别人只看得到你减了百分之几。想公开去「我的」里打开开关。
- 建议固定早上空腹称，数字才有可比性。

## 常见问题

**点错了怎么撤销？**
点主页上自己那一行的对应格子，或者点「今天已打卡」那个按钮，面板底部有「撤销这天的打卡」。

**换手机了 / 清了缓存？**
重新打开链接，在名单里点一次自己。数据挂在成员身上，不会丢。

**名字打错了 / 想换头像？**
右上角「我的」里改。

**不小心点成别人了？**
「我的」→ 最底下「我不是 XXX，换个身份」。

**打开链接说「没找到这个小组」？**
邀请码输错了，或者用的是别人小组的链接。找组长重发一次。

**顶上有个「演示模式」的红框？**
说明还没接数据库，现在的数据只存在你自己手机上，朋友之间看不到彼此。让组长按 [README](../README.md) 配一下 Supabase。

## 用起来之后

这东西的效果不来自功能，来自**每天有人看见你那一格是空的**。所以：

- 把链接置顶在群里
- 谁的格子空了，在群里艾特他
- 周日晚上看一眼「上周」那列，红色的人请客

真要更狠一点，V2 会加断卡自动记欠账（欠一顿饭 / 欠多少钱），线下结算。要不要做取决于你们这几个人现在的自觉程度够不够。
