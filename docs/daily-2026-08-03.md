## 一、今天做了什么

**卡点怎么解决的：** 服务器直连 Docker Hub 和几个常见国内镜像加速站（DaoCloud、1ms.run、NJU、SJTU 等）对 `postgrest/postgrest` 这个非官方镜像全部失败（denied / not found / TLS 错误）——国内镜像加速站基本只对 Docker Hub **官方 library 镜像**生效，第三方组织镜像很难代理到。

绕过方案：服务器直连 GitHub 也不稳（release 资产走 `objects.githubusercontent.com` 超时），改用 GitHub 加速代理 `ghfast.top` 下载 PostgREST 的 **Linux 静态二进制**（`postgrest-v12.2.3-linux-static-x64.tar.xz`），在服务器上用 `FROM scratch` 写一个一行 Dockerfile 本地构建出 `postgrest/postgrest:v12` 镜像，完全不依赖任何镜像仓库拉取。
